# OIBSIP AI Chatbot

Developed by Antariksh D Sawarbandhe

A modern AI Chatbot built using Python Flask with an attractive user interface. The chatbot can answer common questions, tell time and date, perform basic calculations, provide facts and jokes, and maintain interactive conversations.

## Features
- AI Chat Interface
- Real-Time Responses
- Time & Date Information
- Basic Math Calculator
- Fun Facts & Jokes
- Responsive Design
- Flask Backend
- Attractive UI

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## Run Project

pip install -r requirements.txt

python app.py
